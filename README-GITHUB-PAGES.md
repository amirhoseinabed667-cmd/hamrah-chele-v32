# همراه چله V32 — GitHub Pages

این بسته فقط نسخه وب/PWA برنامه است و برای قرار دادن روی GitHub Pages آماده شده است.

فایل‌های اصلی باید در ریشه Repository قرار بگیرند:
- index.html
- manifest.json
- sw.js
- contact-config.js
- icon-192.png
- icon-512.png
- splash.png

برای فعال‌سازی GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root) → Save

اتصال «ارتباط با ما» با EmailJS در contact-config.js تنظیم شده است. مقصد ایمیل در Template سرویس EmailJS قرار دارد و داخل این پروژه ذخیره نشده است.
